# Shopsmart-checkout-analytics
A/B test & retention analytics for a checkout redesign

## Key Findings
-Checkout completion rate: Control 10.03% -> Treatment 15.23% (52% relative lift, p<0.001 -- Statistically significant)
-Average revenue per user: Control Rs6.17 -> Treatment Rs9.16 (48% lift)
-Month-1 retention: Control 33.2% -> Treatment 37.6%
-Month-3 retention: Control 8.4% -> Treatment 11.9%
-**Recommendation:** Ship the one-page checkout to 100% of users - the new design outperforms the old on every measured stage: conversion, revenue, and retention.
